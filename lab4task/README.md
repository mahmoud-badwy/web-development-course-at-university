# CSE343 Lab 4 - Todo App (TypeScript)

A simple todo app written in TypeScript (`app.ts`) and compiled to JavaScript (`app.js`).

Features: add, complete, edit (double-click, Enter to save), delete, filter (All / Active / Completed), items-left counter, Clear completed, Clear all.

## Run

```
npm install
npx tsc
```

Then open `index.html` in a browser.
